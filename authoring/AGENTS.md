# 作者改稿权威源

`authoring/current-card.json` 是作者通过“红豆粉 · 角色卡改稿台”保存的当前角色卡权威源。续更角色卡前先读取默认分支上的该文件并记录 blob SHA，再比较其他历史卡和发布版。作者手改的文案、世界书结构与未知字段以此文件为准。

执行修改时保留未涉及的规则、正则、酒馆助手脚本与固定 Git/CDN 加载地址。需要同步传统顶层字段时只同步实际改动的字段，避免以旧镜像覆盖 data 内新文案。

提交前重读此路径并检查 SHA；远端出现作者新改动时先合并或展示具体冲突，避免覆盖。整卡重新打包、更新发布目录和真实酒馆测试分别执行，不将编辑器文字预览作为 MVU / EJS / 远程脚本验收证明。

本文件约定仅用于本目录的角色卡续接；网站源码由 Sites 维护，当前角色卡修改不会自动发布到既有 CDN 发行版。
