# 御影神社 · 街区漫游 1.15.0

红豆粉的御影神社角色卡远程运行包。这个目录与仓库的通用地图插件独立。

## 使用

导入 `cards/巴卫_御影神社_街区漫游_v1.15.0_昭和旧物回忆版.json`，启用酒馆助手脚本。卡内保留角色资料、世界书、初始化规格和四个远程加载入口。无需另外导入本目录脚本，避免重复运行。

每个加载入口使用固定提交和版本校验，依次尝试 jsDelivr、testingcf 和 GitHub Raw。网络恢复后可点脚本按钮“重新加载资源”。若远程模块已经开始执行但启动报错，应停用并重新启用该脚本，避免重复注册监听。

首次加载和未缓存资源需要网络。图片和字体使用固定资源提交，避免脚本与资源混版；图片链接本身不是三源自动切换。

## 1.15.0 · 昭和旧物回忆册

十处散策各自收录一件旧物；团子小店另有可选的玻璃弹珠摊位挑战。收集 3、7、11 件不同旧物时，回忆册依次翻开三段短篇。弹珠挑战分三局，每局要观察木沿、选路线与力道；走偏后可以无惩罚重试，也可以请巴卫提示，或跳过加赛只收好团子。

回忆册保存在当前设备、当前浏览器的本地存储，不调用模型、不写入 MVU 状态、不兑换资源或好感。可以导出/导入 JSON 备份，也可以复制已收录摘要带入对话，让巴卫沿着真实完成过的互动接着聊。清理网页数据或换设备时，需先导出并在新设备导入。

昭和感来自旧糖纸、车票、玻璃弹珠、纸灯和街角小店的生活细节；当前故事仍在现代小镇，巴卫仍是狐妖神使。回忆册不推断玩家的年龄或真实童年。

本版实现保留独立弹窗结构。代码内的回忆册与小游戏结果由固定脚本生成，不依赖模型生成，也不会自动发送对话。

## 1.12.0 · 独立散策小游戏

地图状态栏只保留十地入口；点击互动点后由第四个酒馆助手脚本打开隔离样式的独立全屏弹窗。弹窗先展示预绘场景、玩法说明与无倒计时规则，再进入游戏；支持 Escape、关闭按钮、焦点返回、手机触控和减少动态效果。游戏结束后把结果写回当前页面的散策手帖。

R04 纸舟关升级为分三道水门的河道闯关：根据船形看到不同可通行水道，拖动画布里的纸舟穿过水门，选错会停岸并可重试；也保留三个大按钮，方便键盘与不便拖动的玩家。场景图用预绘插画，河道动线由 Canvas 绘制；其他游戏继续使用原生 HTML/CSS 交互和插画，SVG 只负责小图标。

卡片只增加一个约 5KB 的固定版本加载器；游戏引擎、样式、河道画布与按需字库仍放在仓库，不内嵌到角色卡。实测 375px 手机视口、弹窗关闭回焦、手帖结果回传、误选恢复和拖动三关。完整记录见 `QA-1.12.0.md`。

## 维护

`assets/` 保存二进制资源，`asset-manifest.json` 保存完整性哈希；`runtime/` 保存四个远程模块；`src/` 保存可审阅的场景、活动、图标与导航源码；`tools/` 保存构建和加载入口模板。

重建当前的场景和面板模块：

```bash
python tools/build_roam.py
python tools/build_minigames.py
```

更新漫游界面的汉字字库时，先用 Google Fonts 的 Noto Serif SC 可变字体生成仅包含缺字的子集，再发布新资源提交并更新 `src/scene-host.mjs` 中的固定资源地址：

```bash
python tools/build_roam_font.py --font-source /absolute/path/NotoSerifSC.ttf
```

从原始重打包卡重建模块：

```bash
python tools/build_mikage.py --card /absolute/path/original.json --manifest asset-manifest-v1.7.1.json --output /tmp/legacy-runtime --asset-commit 1d45da7c4c4c44837fca70ac7301c06ab762d71a
```

修改代码或资源后应发布新提交，并更新卡内加载器的固定版本及提交。不要直接让稳定卡追踪 `main`，避免后续更新影响已有玩家。

公开仓库及 CDN 提供轻量分发和集中维护，不构成访问控制或防盗。原素材的作者署名、权利与字体许可不因迁移改变；未向第三方授予新的使用许可。
