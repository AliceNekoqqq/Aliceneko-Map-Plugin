# 御影神社 · 街区漫游 1.7.1

红豆粉的御影神社角色卡远程运行包。这个目录与仓库的通用地图插件独立。

## 使用

导入 `cards/巴卫_御影神社_街区漫游_v1.7.1_轻量CDN版.json`，启用酒馆助手脚本。卡内保留角色资料、世界书、初始化规格和三个远程加载入口。无需另外导入本目录脚本，避免重复运行。

每个加载入口使用固定提交和版本校验，依次尝试 jsDelivr、testingcf 和 GitHub Raw。网络恢复后可点脚本按钮“重新加载资源”。若远程模块已经开始执行但启动报错，应停用并重新启用该脚本，避免重复注册监听。

首次加载和未缓存资源需要网络。图片和字体使用固定资源提交，避免脚本与资源混版；图片链接本身不是三源自动切换。

## 维护

`assets/` 保存二进制资源，`asset-manifest.json` 保存完整性哈希；`runtime/` 保存三个远程模块；`tools/` 保存构建和加载入口模板。

从原始重打包卡重建模块：

```bash
python tools/build_mikage.py --card /absolute/path/original.json --manifest asset-manifest.json --output runtime --asset-commit 1d45da7c4c4c44837fca70ac7301c06ab762d71a
```
