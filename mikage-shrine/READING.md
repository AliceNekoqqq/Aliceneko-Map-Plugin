# 御影神社·正文美化 1.0.0

独立酒馆助手脚本，沿用固定Git/CDN模块加载。开场题图、和纸正文、页边樱枝、绳结过渡及状态栏配色沿同一阅读主题工作。

## 使用

已集成该脚本的角色卡直接使用。旧卡可只导入 `components/mikage-reading-1.0.0.json`，启用“御影神社·正文美化”，再刷新一次聊天。两种方式选择一种，避免重复导入。

消息上的“阅读设置”或脚本按钮“正文阅读设置”可切换和纸／夜读、标准／大字／更大、装饰、动效及总开关。关闭美化恢复原消息显示。偏好仅保存于当前浏览器，不写入角色卡、世界书或MVU。

## 边界

- 正文继续使用原生聊天节点与原有Markdown处理，文字可以复制、编辑及重生成。中文引号不被强行解释为巴卫台词；已有 `q`、强调和引用使用相应样式。
- 只有实际开场完成标记才展示开场题图；后续消息使用轻量阅读面。立绘依据该楼层已记录衣装与现有形象目录，缺少依据时保留场景、不编造形象。
- 状态栏保持现有准确楼层读取和最多两个活动场景的规则。本组件只统一已知界面的外观，不改寻路、奖励、变量、委托及面板业务。
- 首页、状态栏和已知同源面板使用共用主题。不同来源或不支持的界面保留原样。关闭或切换角色时清理样式与订阅。
- 阅读界面是可伸缩实现，并非将生图稿整张贴成背景。当前已实现纸面、樱枝、印记、题图、灯笼及分隔；复杂金饰与原图逐像素一致性仍需真实浏览器视觉验收。

## 维护

源文件为 `src/reading.mjs`、`src/reading.css`、`src/reading-frames.css`；`tools/build_reading.py` 将它们编译为一个可经现有加载器执行的模块，不包含相对运行时import。

模块发行路径 `releases/reading-1.0.0/reading.mjs`，独立于原有六个模块。旧发行版不被改写。集成卡只新增本脚本并同步版本号，保持作者文案、世界书与六个原加载地址。
