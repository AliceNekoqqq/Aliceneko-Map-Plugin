# Mikage Shrine 1.29.0 scene module

This release bundles the wardrobe, movement and scene runtime for the v1.29.0 card update.

- Runtime entry: `scene.mjs` (`VERSION = 1.29.0`, `SCRIPT_ID = scene`)
- Outfit images are pinned to artwork commit `f4cf643d2b637db99edf2113491e21a370c2973f`.
- Source catalogs: `src/wardrobe-config.json`, `src/scene-host.mjs`, and `runtime/scene.mjs`.
- Offline checks: `node --check`, wardrobe quest tests, and walk atlas preload/lifecycle tests.

Real SillyTavern host acceptance is separate and has not been performed in this workspace.
