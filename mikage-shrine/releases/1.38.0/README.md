## 玩法

在神议后的纸台上选择重逢、远行平安或同行照应的心愿；依次理顺4/5/6个线结的三组红线。数字线结可拖动、选中后点纸台空处移动，也可用方向按钮或原生键盘方向键微调。几何检查实时标出交叉处，线结互挤或相邻线段折叠也不能通过；不要求复刻唯一位置，无计时与失败惩罚。当前组可重摆，已完成的组保留。可请巴卫扶住一端，每次只移动一个线结，协助次数如实记录。

按纸样完成上/下/上三次穿绳，再用原生滑条调节松紧。错穿只重试当前步；太松、太紧分别提示。必须确认收结才算完成，不把“穿完但未收结”记成完成。结束前可托住线结、问放在哪里或打趣巴卫，也可直接留笺。途中可收起散线；结算明确记录已解组数、穿绳次数、是否收成，且每局一次。

只使用浏览器旧物回忆册的新ID `R09-THREAD`。旧R09太鼓纪念及其他记录保留，不迁移或覆盖旧ID。全部操作为本局临时状态；只在确认留笺时调用既有本地回忆接口，不发送聊天、不调用模型、不写MVU、好感、资源、解锁、关系或正式祈愿结果。场景为本项目同人小游戏，不声称是原作事件。可导出结缘笺，存储被拒时保留当前结果并提示导出。

数字线结46px；内容可纵向滚动。后台/失焦暂停，回来手动继续；内容重建保留可继续操作的焦点，三次穿线后转到标题再可Tab至松紧滑条。关闭取消指针状态、监听、ResizeObserver、衣柜订阅和导出URL，并由现有弹窗壳恢复入口焦点及页面滚动。没有持续帧循环或新增定时器。

设计参考实际阅读 https://irodonia.com/ja/games/untangle-game/ 的操作说明，采用常见线交叉谜题的拖点、点选移动和方向微调输入思路；没有复制其代码、美术、关卡或页面。网页只做文字阅读，未宣称运行过参考站。最终视觉检查使用实际构建模块375px与1280px截图。
