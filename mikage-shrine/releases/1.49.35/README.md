# 1.49.35 场景立绘校准检查点

作者从1.49.34 GIF指出立绘位置和大小不统一。原因是旧场景对所有原始画布使用285%宽度及-85%偏移，忽略不同尺寸、透明留白和人物脸部位置。常服与校服原图的尺寸分别为1024×1536、916×1717，统一画布缩放无法统一人物。

## 本轮处理

- 在17张实际素材上核对字节、尺寸和可见内容，逐张标定成人脸部中心、眼线与下颌；16套成人衣装使用同一显示目标，保留原姿态、头饰与发型差异。
- 幼狐沿小体型完整显示，单独使用实际可见人物边界；没有拉成人比例。
- 使用src/scene-portrait-framing.json维护已核对的原图SHA256、字节、尺寸与锚点。只改scene展示CSS和定位逻辑；原图文件、固定URL、共享美术目录与其他界面保持。
- 图片加载、窗口/容器尺寸变化时重新计算显示位置；ResizeObserver有window.resize回退并在清理时断开。仍从本楼状态取得衣装与同地点判断，错误图片收起，未知衣装采用原常服。
- 不新增图片下载种类、预加载或运行库；按原行为只读取当前衣装。正常正文、原小人和热点、菜单位置、文字玩法及归档/API均保持。
