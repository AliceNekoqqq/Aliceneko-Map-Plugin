# 1.49.44 衣橱图册

导入本目录的 `card.json` 并更新酒馆里的原角色。两个角色的服装图册直接使用各自衣装的庭院像素小人。庭院正面、侧面、背面和图册都按源图的等边比例渲染。试衣台保留全身立绘，移除展衣照影、轻晃香囊和走两步三个操作。

衣橱使用浅纸色、梅紫选中态和试衣台细金线。手机端采用三列图册，庭院形象和衣装纪念位于图册下方。原换衣、解锁、购买和纪念名写入逻辑沿用。

## 构建与校验

- 权威卡基准 `5b701f58bc5acc02e20785db579677f9bfa8167a`，卡片 blob `116aba38eb4138534e254415607513f2c978e44e`。仅修改两处版本号和檐下生活组件的加载器名称与地址。其他六脚本、41 条世界书、正则、作者文案与扩展字段逐项相等。
- 运行模块固定到 `902b542f03e6d671415216e4ac04e5e6b78c98e1`。主 CDN、testingcf CDN 和 Git 原文与本地模块 SHA-256 一致，值为 `ee33e1e24612e7edcf6138efdeff9766eb284c5e57e0a3ecb7f976c7ce4f21a4`。卡片 397234 字节，严格体积检查通过。
- 用发布组件、真实像素图和游戏状态引擎在 Chromium 的 320、375 和 1280 像素宽度复查两角色图册、换衣写入、锁定预览、四向切换、键盘焦点和横向溢出。11 项加载器、开场兼容与衣装支线检查通过。尚待用户手机的实际酒馆验收。
- 维护源见 `src/wardrobe/gallery.css` 与 `src/wardrobe/gallery.js`。通过 `tools/build_wardrobe_gallery.py` 从 1.49.39 的发布面板生成新版模块。旧卡加载固定提交，需导入新版才能获得更新。
