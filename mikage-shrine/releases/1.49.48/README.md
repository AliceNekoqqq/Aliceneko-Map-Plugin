# 1.49.48 神社新笺与玩法说明

新笺上的每个名称都能点。地区展开地点详情，衣装打开指定角色的预览，生活功能切换对应页签，配方定位到配方卡，衣装支线指向悬挂入口，主线绘马展开对应木牌。散策结算的短篇名称打开回忆册并定位到正文。

首次进入对应功能时会展开简短的玩法说明，之后可以随时重看。从新笺进入时，说明里的「查看已定位条目」会将焦点移到目标。手帖关闭后回到原来的按钮。手机上的生活页签会自动露出当前选项。

打开提示只读取系统保存的进度。动身、试穿后的更换、交易和接取委托仍由玩家操作。教学阅读记录留在本设备。

导入 `card.json` 更新角色卡。正文美化 1.1.5、御影手帖和独立小游戏 1.49.48 固定在 `1a85b94c31b71430ae213546ca2270926e3f0582`。与上一版的逐字段比较限于版本和这三个加载器。实际浏览器通过深链接、第一次与重复查看教学、关闭后返回焦点、新旧存档及回忆解锁测试，真实手机酒馆待复核。
