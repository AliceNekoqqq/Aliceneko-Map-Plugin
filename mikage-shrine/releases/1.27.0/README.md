# v1.27.0 神域背景与分块

本目录为最新卡的四个运行模块，不使用旧版tools/build_card.py重建。

九地各重绘白天/黄昏/夜晚共27张背景，均为1536×1024；御影神社保留原有三张。前景地面、三十个互动点的落脚位置及九地巡游路径已配套调整。十地均纳入总览分块，取消地图外电车入口；分块可整块点选，并有44px快速地名按钮。新版地区图块按当前时段展示对应风景。

保留全部存档字段、主线与地区ID、任务门槛、资源数值及衣装规则。只调整地图展示坐标、图块形状、背景与场景氛围短句，未重做小游戏机制。模块版本统一为1.27.0，防止继续复用旧加载缓存。

验证：40,000个点无分块空洞或重叠，10个标签位于对应分块内，30个互动点路线位于可走范围；10段内嵌HTML脚本编译通过；40组旧存档迁移与数值门槛一致性回归通过。已逐张查看全部背景。未做真实SillyTavern/手机浏览器实测；差分图为生成式绘制，细小纹理可能有变化。

背景使用内置imagegen生成；地图几何和文字由原生SVG/HTML精确绘制。字体为Noto Serif SC子集，许可与来源见素材目录。
