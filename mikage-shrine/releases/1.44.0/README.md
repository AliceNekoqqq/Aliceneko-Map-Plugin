# 1.44.0 神域图卷互动版

地图插件改为实绘旅行手卷：朱红织锦、木质卷轴、烫金木牌、纸质地区签和风景明信片。十地区仍使用发布版实际配置与同一批目的地风景；地图区块、地名签、明信片三处选择保持同步。当前地区、查看地区、开放状态分别表达。手机上下流式布局，宽屏地图与明信片并排。

地区签有按压与轻抬反馈，切换目的地带动明信片；罗盘拨转、樱枝落花、折纸狐跳跃，罗盘每三次拨动带动纸狐。装饰效果不持久化、不发送消息、不推进时间、不写正式状态。粒子最多24个；离开地图、文档隐藏、减少动态效果切换、销毁时清理。减少动态效果下仅短透明度反馈，无位移或粒子。

前往仍调用既有 ShrineUIBridge 的 travel，单次在途请求跨地区禁用，提交中/失败可重试/已提交等待剧情确认各有反馈。不会把“已提交意图”显示为“已抵达”。地图查看选中项由现有局部变量保持，刷新不跳回当前地区。新增文本使用独立完整字形子集，不依赖宿主恰好有中文字体。

实际 Chromium 渲染维护HTML，320/375/1000宽度检查通过：十区/十地名签、真实区块点击、详情同步、锁定与当前地区、刷新保留选择、明信片和纸签动画、三装饰、三次罗盘彩蛋、粒子上限、无横向溢出、暖色键盘焦点、减少动态效果、关闭与销毁、原四面板切换。前往单次提交、切换地区后仍禁用、失败重试、提交不伪造抵达通过。图片缺失时地名与锁定/操作仍可辨识。真实素材按本地文件映射，仅证明本地布局与逻辑。
