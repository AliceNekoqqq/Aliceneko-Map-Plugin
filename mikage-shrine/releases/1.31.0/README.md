# 1.31.0 · R02 樱坂拾页记

逐项重做的第二个小游戏。已重做R01狐火茶席、R02樱坂拾页记；R03–R10仍是之前交接的待改造项，不把现有新标题误记为已实现。

## 玩法与边界

- 三段各四个遭遇：校门散页、樱坂起风、坡下相逢。左右换道拾回六张散页，避开黑羽和过路人。
- 两次路段间歇可选择樱花一侧或树荫一侧，改变后续分布；阵风会在途中把纸页吹偏，提前显示方向。
- 两次本局巴卫协助，挡风或示意人群让路；不是妖力/好感资源。漏页或停步仍可到达终点。
- 终点将失主出示的三张便签按时刻排序，再选择自己交还或请巴卫递交。拾回数量如实记录，零拾取结果不虚构已交还纸页。
- 自动、慢速、逐步模式；按钮、键盘左右/空格、道路横滑；切后台/失焦暂停，手动恢复；销毁停止帧循环与监听。
- 背景复用已绘制的宇庭高校白昼/黄昏/夜晚，人物通过共享API读取当前衣柜穿着，保留1.30.1图集裁切。不会强行换校服或确认学籍、关系，不触发变形或亲密行为。
- 只写既有本地回忆册R02稳定ID及散策手帖，不调用模型、不写MVU/主线/关系。拒绝存储时保留页面内记录并提示导出；回忆册schema和旧ID保留。
