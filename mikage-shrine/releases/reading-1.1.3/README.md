# 正文与状态栏美化 1.1.3

对应用户手机截图的三个改动：分隔牌文字背板、设置窗口顶部截断、状态栏层次。仍限reading模块，变量/初始化/MVU和六个旧加载器保持原样。

檐下此刻：保留独立绳结牌PNG，文字span在和纸、夜读和关闭装饰三种情况下均透明，无额外白色矩形。

设置窗口：从body移到documentElement根层，避开聊天/body变换形成的定位容器；按visualViewport的宽高与偏移确定覆盖层边界，resize/scroll时调整，窗口关闭时解除监听。标题与关闭按钮使用粘性顶部，内容内部滚动，打开与恢复焦点使用preventScroll。设置面板自有颜色/按钮样式局部隔离，保留原选择、键盘关闭与焦点圈行为。

状态栏：保留四主两次入口与事件；主入口改为有间隙的纸签卡、柔和内高光与阴影，不同纸色分组，图标轻浮起；场景增加圆角金边与浅阴影；顶部细章线、时段纸签、委托草绿标签和底部细节统一。触摸设备取消纯hover造成的深紫整块残留；桌面hover限定到hover:hover/pointer:fine。夜读有对应变量。

实际源改动96行。模块44419字节，无Base64；源码到模块重复构建、语法、原DOM生命周期、三种助手标记、旧模块iframe联动与Git备用回归通过。新增回归：带transform的body、可见区355×520偏移24px、缩到320高/偏移120px后同步边界，关闭后监听释放，标题sticky，以及分隔文字白天/夜读背景透明。

新增主按钮渐变端点对比度最低5.26:1，委托标签5.52:1，原文字与辅助字最低4.91:1。DOM/CSS检查不代表真实浏览器布局；手机实显与触控仍待复核。测试依赖仅存在开发目录，不进入卡片。

图片继续固定GitHub既有素材提交；先发布此模块，再以真实提交生成1.49.43的第七加载器和独立组件。
