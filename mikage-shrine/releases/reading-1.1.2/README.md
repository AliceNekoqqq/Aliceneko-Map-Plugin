# 正文与状态栏美化 1.1.2

范围：reading模块的消息识别、正文CSS和已知iframe主题CSS。MVU、空值修复、世界书、场景数据与六个旧加载器不在本次改动范围。

修正正文只接受role=assistant而状态栏已兼容is_user=false/mes_type=assistant的不一致。为三种助手标记与玩家排除增加了回归，检查保留原文字节点和记录数据。

视觉：暖白和纸 #fbf6ee，正文 #352e38，梅紫 #754d68，浅金线 #d5c2a1，柔紫灰 #eee5ee。夜读使用独立暗色变量。主文字/辅助字/主按钮七组配色对比度均大于4.5:1。

离线验证：模块语法、源到模块重复构建、原DOM生命周期及新增助手标记回归、旧模块iframe联合模拟、固定Git加载器回归；CSS在实际状态栏DOM解析通过，九个原控件保留，画风与视图按钮计算grid-row均为2。该检查不是浏览器几何或手机截图验收。
