## 玩法与边界

幼狐是继承设定中暂时变小的巴卫，不是新增宠物。独立临时弹窗三段：解开三张雷网、布置避风处、留出空隙等回应。无倒计时、生命、伤害或正式养成数值。布置与回应是本项目同人小游戏情境，不把它们写成原作事件。

- 起始三种神态：耳尖绷紧往檐影缩、柱后悄悄看你、总看台阶。神态对应休息、走近或离开的结局，均可完成；没有把所有情况都变成必须亲近的最优解。
- 每张雷网的三个结顺序不同。按一、二、三解开，可手指/鼠标连划，也可逐个点按、聚焦结点按回车。错序只重置当前张，已解的网保留；可重摆当前线头。没有触碰到小狐的解网路径或惩罚动画。
- 避风垫可拖动、用两条原生滑条调整或选择位置预设。只有檐下干地范围（x55–78、y40–65）、竹屏/挡风布已布好且台阶退路勾选开放，才能进入陪伴；湿处、风口、没有挡风或堵退路均有具体提示，可随时调整。
- 陪伴时观察耳朵/尾尖、说自己不拦路，选择近一步或退到檐边。挪近时巴卫会退开，反复等待不强制亲近；退远后两次主动等待，按起始神态由他自己休息、走近或沿廊离开。等待是一次本地操作，不要求真实计时或联网。
- 笹饼可放在远处或收起，不递到嘴边、不记录进食，不是完成门槛。没有摸耳朵、强抱、投喂按钮，也没有靠触碰恢复正式妖力。三种结果都可以不放食物完成。
- 完成后摹下地上爪迹或尾影；不是要求休息/离开的巴卫按爪印。任一未完阶段可提前留笺；已解几张、避风处是否完成、是否等到回应如实区分，当前未完步骤不记为完成。每局一次结算。
- 仅新增本地R08-FOX与既有页面手帖回调，旧R08及其他回忆保留。没有模型调用、聊天/MVU写入、资源/好感/背包/解锁/主线改变。幼狐是本局形态，不改玩家或巴卫已选衣柜服装，不自动记录恢复成人形。
- 隐藏页面或失焦暂停手势和操作，回来手动继续；键盘等待重建内容时保留按钮焦点。关闭取消手势/事件/衣柜订阅并回收导出URL、回焦。图片404用文字幼狐降级，仍可留笺；拒绝存储时保留本页结果并导出。

旧R08萤火顺序处理器从当前入口移除；历史发布和旧R08竹球回忆原样保留。
