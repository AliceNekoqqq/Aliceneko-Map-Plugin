# 1.49.33 档案键盘操作检查点

延续花笺手帖交付，只修复任务档案弹窗的键盘焦点。旧版在首个“关闭”按钮上按 Shift+Tab，会把焦点送到弹窗外的“任务档案”入口。新版按实际可操作控件双向循环；折叠 details 的内容、隐藏或禁用控件及负 tabindex 不参与循环。初始弹窗焦点或外部焦点进入时，Tab/Shift+Tab分别回到首项/末项；Esc关闭后返回原入口。

## 已验证

- 在实际1.49.32模块中复现旧问题；新检查对旧版失败。
- 1.49.33实际构建模块在320/375/1000宽、520/812高的六组组合通过：首尾双向循环、展开设置后的末项变化、禁用/隐藏/负tabindex排除、外部焦点回收、456步浏览器键盘遍历、Esc与入口返回。
- 键盘检查前后聊天档案、世界书副本、设置及模型请求不变。
- 原档案编辑与草稿跨刷新、主/独立方案请求配置（模拟生成）、凭据隔离、回档、聊天切换和迟到结果隔离、事件清理与自动失败只尝试一次回归通过；零真实模型调用。
- 去掉唯一键盘处理器变化并还原版本后，完整archive模块与1.49.32逐字一致；样式、归档核心、模型配置和保存路径保持。其他五模块、39条世界书、五正则和六脚本身份保持。
- 构建工具支持--dry-run与--check，核对基线六模块哈希、两张现有装饰素材及整模块逆向保持。检查点候选沿用固定Git加载，不内嵌运行代码。

## 依赖与边界

继续使用原MVU Zod混合卡链路：卡内39世界书、初值、五正则和六个加载器已经包含；schema/validator在mvu远程模块。宿主仍需SillyTavern、酒馆助手及EJS模板能力，原MVU/Zod及美术字体远程路径保持；没有新增安装项、运行库或API接口。地区加载继续按单加载器内部地址顺序回退，不增加第二套启用脚本。

这是隔离模拟宿主中的实际源码检查，真实酒馆导入与宿主样式处理、线上CDN执行、手机键盘/触控/字形、实际模型和作者接受仍待验收。没有把浏览器模拟结果计为实机通过。历史暂停的全局玩法审查不在本轮范围。
