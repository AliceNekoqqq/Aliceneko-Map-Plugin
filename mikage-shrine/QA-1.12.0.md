# 1.12.0 验收记录

## 本版内容

- 十地互动从状态栏源码中拆出，改由第四个远程酒馆助手加载器按需打开全屏弹窗。背景页面滚动锁定；关闭和 Escape 会移除弹窗并恢复滚动与焦点。
- 弹窗以 Shadow DOM 隔离样式，开始前展示预绘场景、玩法说明和注意事项。游戏仍写入同一会话的散策手帖，不增加 MVU 根状态、货币、好感或额外消耗。
- R04 纸舟保留纸色、船形与折纸步骤，新增三道根据船形变化路线的河道水门。玩家可拖动 Canvas 里的纸舟过关，也可以点三个方向按钮；误选有明确反馈，可重试，无倒计时。
- 角色卡保持轻量：4 个约 5KB 的远程加载器；互动引擎、样式和画布逻辑存放在仓库。状态栏构建产物为 90,624 字节，不再包含活动源码、活动 CSS 和活动美术表。
- 最终卡片约 294 KB，四个加载器各约 5.3 KB；没有内嵌 Base64。游戏模块固定于代码提交 `7577d4fb0a3de50bdb2141c86e0645f6c387d18c`，新增字库固定于资源提交 `b6d0a11791e2b676d0107ee9412ae8fddd7f66ca`。
