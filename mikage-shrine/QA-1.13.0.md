# 1.13.0 验收记录

## 本版内容

- 为 R03 团子、R05 旅票、R07 叶拓、R08 萤火、R09 太鼓和 R10 灯阵增加六张专属预绘场景图。
- 团子有搭配、逐颗调火、蘸料与点缀三个阶段；火候不合适可调整后重试。
- 旅票规划有序的两处停靠与终点，再按路线逐站盖章。
- 叶拓根据线索寻找三类叶片，并通过 Canvas 手动涂印；键盘与触屏玩家也可用大按钮压印。
- 萤火记忆分两段递增，可重播光序或显示数字提示，不计时。
- 太鼓演奏三段四拍节奏，也可自由敲击；鼓面通过 Canvas 绘制。
- 灯阵可选择布局与颜色，六盏灯在保存前都能重新调整。
- 所有小游戏仍通过第四个酒馆助手加载器打开 Shadow DOM 独立弹窗；角色卡不内嵌游戏源码、样式或图像。

## 验证

- `node tests/activities.test.cjs`：十地完成与重玩、团子火候、旅票站序与盖章、叶拓 Canvas 和键盘回退、两轮萤火记忆、太鼓 Canvas 与节奏、纸舟按钮/拖动路线、手机布局、键盘操作、44px触控目标、销毁清理与回调次数均通过。
- `node tests/minigames-plugin.test.cjs`：独立弹窗、不扩展状态栏、预览到游戏、结果回传、关闭/Escape、滚动恢复、375px布局和预绘图片均通过。
- `node tests/navigation.test.cjs`：479条路线、554条密集采样边通过。
- `node tests/time-of-day.test.cjs`：时段解析、30张地区场景和缺失资源回退通过。
- `node tests/wardrobe-quests.test.cjs`：7项衣装任务通过。
- `node tests/wardrobe-browser.test.cjs`：375px与1280px视口均无横向溢出，衣装图片加载完整。
- `python tools/build_minigames.py` 与 `node --check runtime/minigames.mjs`：通过；游戏引擎构建产物约112 KB，留在仓库并按需下载。
- `python tools/build_card.py`：从1.10.0原始卡生成1.13.0角色卡，卡片295,464字节；四个远程加载器分别为5,333、5,369、5,365、5,381字节，未嵌入Base64。小游戏引擎固定指向代码提交`1e925c3e56a8b303d0e0134ad2cb5ead65654a06`；六张新图固定指向素材提交`f616ec7a3587810407df23f4e8e685786306e8f7`。
- 手机截图复核团子、旅票、叶拓、萤火、太鼓和灯阵场景；交互画面使用预绘背景图、HTML/CSS与Canvas，SVG只留作少量图标。
- 未在真实 SillyTavern 实例内导入测试；脚本加载顺序和实际聊天消息时序仍需玩家导入角色卡后实机验收。
