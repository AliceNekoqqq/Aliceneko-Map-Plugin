# 1.8.0 验证记录

## 批判性审视与修正

旧版十个地点只用矩形边界与直线移动，不能匹配水边、弯道、站台和湿地栈道。背景原图/图集单格为 3:2，旧 4:3 场景又引入裁切或拉伸。十八个地点热点中十五个仅显示固定句子；文字牌覆盖风景，部分面板在人物未接近前直接打开。神社专属摆设还因 CSS 使用无效 `[data-region!="R01"]` 选择器而泄漏到外地。

本版改为完整 3:2 地图、逐图地面多边形与安全寻路、物件锚点和站立点分离、到达后才触发互动。用小图标和高亮取代场景文字牌，保留触屏和键盘可访问名称。十地有不同的可操作小舞台，完成后留下当前会话小记；可主动加入对话草稿，不自动发送或改写游戏数值。

## 已通过

- 三个 ESM 运行模块及嵌入脚本语法检查。
- 导航：480 条路线、619 条边密集采样，全在地面内；隔断不穿越，凹角正确绕行；十地的出生点、巡游点和热点接近点均可达。
- 真正 Chromium 手机/桌面浏览器：十地区各两种尺寸均为 3:2，无横向溢出，无缺失图片，无脚本异常。
- 20/20 地点互动均在人物到达后打开；采集 1,934 个实际行走脚底点，越界 0 个。
- 逐图视觉检查：临海站台不上轨道、湿地走木栈道；小路高亮与画面地面相符；外地不再出现神社坐垫/灯笼/风铃。
- 十种活动均可完成、重玩；猫需要耐心，纸舟选错可重试，萤火可看提示，太鼓可自由敲击，灯笼最终配色由确认按钮锁定。回调本局仅一次。
- 面板地图/衣柜/绘马/生活四页回归通过；已拥有衣装能保存，锁定泳装仅预览，EMA-1接取正常。
- 活动重绘保留键盘焦点，不抢组件外焦点；375px 活动布局无横向溢出，活动触控目标至少 44px。
- 快速改点/跨地区/销毁场景后旧活动不再触发，销毁后不再移动。
- 字体：新增 221 字的合法 Noto Serif SC 子集；新界面全部 845 个中文有字形覆盖。修复活动 CSS 绕开已加载字体的问题，R01/R06/R09 的真实手机/桌面截图已确认无方框字。
- 新字体 CDN 返回 HTTP 200，字节数、SHA256 及跨域头验证通过；既有图片及字体保持原固定资源提交。

## 实际范围

这些是独立浏览器配合模拟酒馆桥接的测试，未连接用户真实 SillyTavern、聊天模型或真实长期存档。原有 MVU 内部 0.6.0 契约和角色/世界书未修改；真实消息事件顺序、全五章及全部生活动作组合仍需要实机体验。

散策小记是本次页面会话内的轻记忆，刷新、切换聊天或重选消息后可能清空。它不是金币、物品、好感或主线奖励；正式生活操作保持既有库存与规则约束。

测试入口：`tests/navigation.test.cjs`、`tests/activities.test.cjs`。后者需要 Playwright 和 Chromium（`CHROMIUM_PATH`）。
